# Course Finder — CTA 7

A Python console program that retrieves a course's room number, instructor, and meeting time using three separate dictionaries keyed by course number.

## Run

Requires Python 3.9 or later. No external packages are needed.

```bash
python3 CTA_7_course_finder.py
```

Enter `CSC101`, `CSC102`, `CSC103`, `NET110`, or `COM241` to view course details. Input is case-insensitive, and surrounding spaces are ignored. Enter `q` to quit.

The program supports repeated lookups and handles blank input, unknown courses, end-of-input, and keyboard interruptions.

**Note:** Meeting times are fictional values used for this assignment.
